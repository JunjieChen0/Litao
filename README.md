# Litao

**青柠集 · 校园二手交易平台（课程设计 Demo）**

面向本校学生的轻量二手交易原型，展示移动互联网平台的供需匹配、信息流与用户互动能力。
按课程设计要求：**不做真实支付、物流、推荐算法、后台管理与真实用户体系**。

---

## 快速开始

零依赖、零构建、零后端。三种方式任选：

1. **直接用设计工作台**（推荐）：右侧「设计工作台」已打开 `design/home.html`，11 屏并排显示，可点选、可演示、可拖调节滑块。
2. **本地双击**：打开 `design/home.html` 即可（Chrome / Edge）。页面会把自己装在 390×844 的手机画幅里，按手机窗口看效果最佳。
3. **起个静态服务**（可选，便于手机扫码看）：
   ```bash
   cd design && python -m http.server 8080
   # 浏览器打开 http://localhost:8080/home.html
   ```

> 数据全部保存在浏览器 `localStorage`。想恢复初始状态：进「我的 → 设置 → 重置演示数据」。

## 演示脚本（答辩建议 3 分钟）

按这个顺序点，能完整覆盖「供需匹配 → 信息流 → 用户互动」：

1. **首页**（`home.html`）：看顶部搜索、8 宫格分类、双列商品流；拖到最底看上拉加载的「没有更多了」；点「下拉刷新」看反馈。
2. **分类筛选**（点分类宫格或「更多筛选」）：切「价格从低到高」「50 元以内」，讲分类与价格筛选如何缩小匹配范围。
3. **搜索**（顶部搜索框）：输入「台灯」→ 命中列表；输入不存在的词 → 看空状态；讲关键词匹配与搜索历史。
4. **商品详情**（点任一商品卡）：看图片、价格、成色、描述、卖家校区、交易方式；点「收藏」→ 讲用户偏好沉淀。
5. **联系卖家**（详情页底部主按钮）：自动生成一条咨询并跳到消息列表 → 进模拟聊天 → 发一条消息。讲信息流如何支撑交易沟通（Demo 无真实支付）。
6. **发布**（底部中间「+」）：选图片、填标题/价格/描述、选分类成色 → 「确认发布」→ 跳详情。讲供给侧如何进入平台。
7. **我的发布**（我的 → 我的发布）：把刚发布的商品「下架」→ 回首页看它从信息流消失；再「上架」。讲商品状态管理。
8. **我的 → 设置 → 重置演示数据**：一键恢复初始状态，方便反复演示。

## 数据方案

严格对齐课程设计文档第 6 节的简易数据模型：

```json
{
  "id": "001",
  "title": "高等数学 第七版 上下册 + 课后答案",
  "price": 25,
  "category": "教材",
  "condition": "九成新",
  "description": "几乎没怎么翻过，笔记只在第一章写了几行……",
  "images": ["url1", "url2"],
  "seller": { "id": "u001", "name": "张同学", "campus": "主校区" },
  "status": "在售",
  "createTime": "2026-11-11"
}
```

- `design/data.js` — 15 条真实感种子商品、分类、热搜词、模拟会话
- `design/store.js` — localStorage 封装：发布 / 收藏 / 上架下架 / 删除 / 搜索历史 / 会话生成 / 筛选排序
- 图片用**本地 SVG 插画占位**，不引用外网图片，离线也好看
- 种子数据带版本号，改 `data.js` 后自动覆盖旧缓存

## 设计说明

- **风格**：清新自然 —— 浅绿白底 + 森林绿主色 + 麦黄点缀；中性色带绿调，不用纯灰。
- **画幅**：`app` 390×844（顶部 54px 状态栏、底部 83px 标签栏 + 34px 横条），已按 375×667 / 390×844 / 430×932 三种尺寸实测兼容。
- **排版**：中文 iOS 字体栈，字号阶梯 12/14/16/20/24/28/32，正文对比度 ≥4.5:1，可点区域 ≥44×44。
- **可访问性**：语义标签、`aria-label`、`:focus-visible`、`prefers-reduced-motion`。
- **验收**：`check_design` 11 屏 × 3 尺寸全通过（无截断、叠字、对比度、点击区、固定栏遮挡、死链、脚本报错问题）；`look_design` 已逐屏看过渲染图。
